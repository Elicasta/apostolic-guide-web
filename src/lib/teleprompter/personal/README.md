# I Am Eli Castaneda teleprompter scripts

Two camera-ready, section-based episodes for the personal channel, separate from the Apostolic Guide doctrinal episode library.

- Episode 01: What Does It Mean to Actually Know God?
- Episode 02: Are We So Busy Building a Life That We Forget to Live It?

Each script has nine sections: an opening, seven talking points, and a closing. The content is meant for conversational delivery, with speaker-only notes (`@note`) and KJV Scripture references (`@ref`) where applicable. Use `---` between sections to navigate using the phone remote.

The web teleprompter stores scripts in browser local storage, not in a synced cloud library. The separate v1 personal-channel seed runs once on each device after deployment and preserves existing scripts and later edits/deletions on that device. To use the same edited copy on another device, transfer the script manually until cloud sync is implemented.

Open the script library at `/teleprompter/library` and search **I Am Eli Castaneda**. Select a script, then choose **Present**.
