# Apostolic Motion Engine 0.1

Apostolic Motion Engine turns an approved Pathway narration into a repeatable illustrated explainer instead of a stack of animated title cards.

## Production contract

```text
approved Pathway script
        ↓
Pathway audio
        ↓
SOL-directed visual beats
        ↓
word-level alignment
        ↓
deterministic motion plan
        ↓
continuous-canvas preview
        ↓
saved project.style.motionEngine.plan
        ↓
GitHub FFmpeg/ASS renderer
        ↓
reviewable MP4
```

AI is used where judgment helps. Software owns timing, rendering, layout, colors, safe areas, scene grammar, and output formats.

## Style target

The visual language mixes illustrated Bible explanation, restrained documentary motion, and draw-on/whiteboard behavior inside Apostolic Guide's navy, cream, red, and blue identity.

The engine does not generate random footage for every sentence. It chooses from a fixed visual grammar such as:

- Shema / one-God diagram
- no-rival diagram
- Jesus repeating the Shema
- apostolic witness / open-book diagram
- Word to flesh
- invisible to visible
- baptism / Jesus' name
- Spirit / fire
- authority / throne
- gospel pattern
- Scripture scroll
- recap map

## Theology-safe visual rule

God is not represented as a second human figure. Divine presence is rendered through light, glory, line, word, ring, and symbolic form. Human figures are reserved for genuine humanity and biblical people.

## Source of truth

The saved `pathway_video_projects.style.motionEngine.plan` object is the contract between the browser preview and the renderer. A project can keep the old visualizer template as a fallback. Motion Engine only activates when a valid version-1 plan has been saved.

## Pilot

`God Is One` is the first acceptance pathway because it exercises Scripture progression, Old and New Testament continuity, abstract doctrine, Jesus teaching, apostolic witness, recap, and CTA behavior.

The first review target is the first 60–90 seconds. Review should answer:

1. Is the scene density right?
2. Does the art feel like Apostolic Guide rather than a generic whiteboard template?
3. Are camera moves too still, right, or too busy?
4. Does each visual clarify the narration rather than merely decorate it?
5. Are theological symbols accurate and non-confusing?

After the visual language is accepted, expand the grammar and reusable art asset library rather than hand-authoring every video.
