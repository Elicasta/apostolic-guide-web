# Original carousel design recovery

The owner rejected the Studio 3 redraw and its follow-up. Restore the visual rules retained in `src/pathway-carousel-studio.tsx`, `app/admin/carousel-studio.css` and `app/admin/carousel-studio-rules.css` within the shared preview/export renderer.

Recovered values: 6.5% brand/footer inset, 9.8% mark width, SCRIPTURE PATHWAY label, 49% copy center, 90% title width, 78% body width, 2.3cqw gap, original title fit classes, 2.45cqw body type, original navy/paper/crimson palette, bottom city silhouette, subtle grain, atmospheric lighting and compact crimson emphasis badge. Remove new frames, circles, diagonal graphics and footer rule. Editorial uses Cormorant, Street uses Montserrat, Cinematic uses restrained Cormorant, Verse uses Montserrat and Manifesto pairs Montserrat with Cormorant support.

Copy remains intact. Complete passages retain readable type and measured overflow protection. Manual controls and mobile containment remain. Font rasterization and line wrapping in the shared vector renderer may differ from the historical browser DOM; this is a restoration of source design rules, not a claim of pixel-identical output.

Comparison fixture includes the owner's “BEGIN WITH ONE GOD” example. See recovered-original-directions.png and recovered-original-cover.png. These are test fixtures, not published teaching.
